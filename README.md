## 🎯 Problem Statement
The goal was to explore a cleaned sales dataset consisting of 1,200 orders across 14 variables to uncover patterns, trends, and outliers, turning raw data into actionable business insights before attempting any predictive modeling.

## 🛠️ Tools & Skills
* **Python** (Pandas, Data Cleaning, Exploratory Data Analysis, Statistical Summary Metrics)
* **Data Visualization** (Matplotlib/Seaborn for Boxplots, Distributions, Categorical Breakdowns, Trends, and Correlation Heatmaps)
* **Business Analytics** (Outlier Detection via IQR, Revenue Driver Analysis, Cancellation Rate Diagnostics)
